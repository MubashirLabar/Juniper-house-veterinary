# Juniper House Veterinary

Landing page and style guide for Juniper House, a boutique veterinary clinic in Sarasota.

## Pages

- `/` — landing page (also at `/juniper-house`)
- `/juniper-house/style` — style guide

## Tech stack

Next.js (App Router), TypeScript, Tailwind CSS and Motion.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project structure

```
src/
├── app/                      # routes
├── brands/juniper-house/
│   ├── theme.css             # design tokens
│   ├── content.ts            # page copy
│   └── components/           # ui, patterns, sections, style guide
└── lib/                      # shared helpers
public/images/                # photography
```
